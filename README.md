# Kshreera Sagara

## Overview
Kshreera Sagara is a dairy management mobile application developed to simplify milk collection and farmer management operations.

## Features
- Farmer management
- Milk collection tracking
- Fat & SNF calculation
- Reports generation
- Authentication system

## Technologies Used
- React Native
- Expo
- Firebase

## Installation
1. pnpm install
2. pnpm start

## Future Scope
- AI analytics
- Cloud backup
- Multi-language support
